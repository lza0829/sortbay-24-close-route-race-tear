## 争用收口口径（全局唯一：闭口优先）

关口写口与裁决写口共用同一落锤段（进程锁 + `BEGIN IMMEDIATE` 写事务）：

- 闭口先落锤：在途裁决整笔失败（400「口门已闭，禁止落入」），不改扫描口门列、
  不增在口件数；闭口令同事务把半空登记（`route_inflight`）收口为「已拒绝」（写闸拒证）。
- 裁决先落锤：闭口回执显式带上在口件（`闭口收口_带上在口件`），落账不得悬空。
- 半截（写闸/裁决任一）：写事务整笔回滚、退回对撞前快照，并补记
  `半截回滚_退回对撞前快照` 对撞账本与审计，可重放核对。
- 成功灯只认 `chutes` / `scans` / `route_inflight` / `collision_runs` /
  `audit_events`；历史 `surface_*` / `close_surface:*` / `close_route:*`
  影子键由 `init_db` 一次性清除，不再有任何旁路涂写层。

对账：`GET /api/总览/对账`；重放：`POST /api/对撞/{id}/重放`；
修复：`POST /api/总览/对账/修复`。
